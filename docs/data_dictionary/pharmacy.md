## pharmacy.brand_generic_opportunity

- **dbt model:** `pharmacy__brand_generic_opportunity`
- **Grain:** `data_source`, `claim_id`, `claim_line_number`
- **Materialization:** table
- **Description:** Table that identifies opportunities for generic substitution in pharmacy claims.

| Column | Type | Key / Tests | Description |
|---|---|---|---|
| `data_source` |  |  | Source of the data. |
| `claim_id` |  |  | Unique identifier for the claim. |
| `claim_line_number` |  |  | Line number of the claim. |
| `ndc_code` |  |  | National Drug Code. |
| `ndc_description` |  |  | Description of the drug as per NDC. |
| `brand_rxcui` |  |  | RxNorm Concept Unique Identifier for the brand. |
| `brand_vs_generic` |  |  | Indicates whether the drug is a brand or generic. |
| `generic_available` |  |  | Indicates if a generic version is available. |
| `paid_amount` |  |  | Amount paid for the drug. |
| `total_units` |  |  | Total units of the drug dispensed. |
| `brand_cost_per_unit` |  |  | Cost per unit for the branded drug. |
| `generic_average_cost_per_unit` |  |  | Average cost per unit of the generic drug. |
| `brand_less_generic_cost_per_unit` |  |  | Difference between the cost per unit of the brand and the average cost per unit of the generic drug. |
| `generic_available_total_opportunity` |  |  | Total potential savings from substituting with generics, where applicable, based on units multiplied by cost difference per unit. |
| `tuva_last_run` |  |  | The last time the data was refreshed. Generated by `dbt_utils.pretty_time` as the local time of the `dbt run` environment. Timezone is configurable via the `tuva_last_run` var. |

## pharmacy.generic_available_list

- **dbt model:** `pharmacy__generic_available_list`
- **Grain:** `generic_available_sk`, `generic_ndc`
- **Materialization:** table
- **Description:** Provides a list of pharmacy claims where a generic alternative is available, detailing both brand and potential generic drug costs and descriptions.

| Column | Type | Key / Tests | Description |
|---|---|---|---|
| `generic_available_sk` |  |  | Surrogate key for generic availability. |
| `data_source` |  |  | Source of the data. |
| `brand_ndc_code` |  |  | National Drug Code for the brand drug. |
| `brand_ndc_description` |  |  | Description of the brand drug. |
| `brand_rxcui` |  |  | RxNorm Concept Unique Identifier for the brand drug. |
| `brand_paid_amount` |  |  | Total amount paid for the brand drug. |
| `brand_units` |  |  | Units of the brand drug dispensed. |
| `brand_paid_per_unit` |  |  | Paid amount per unit for the brand drug, calculated as total paid divided by units, if units are not zero. |
| `generic_ndc` |  |  | National Drug Code for the generic drug. |
| `generic_ndc_description` |  |  | FDA description of the generic drug. |
| `generic_prescribed_history` |  |  | Indicates if a generic version has previously been prescribed, 1 for yes and 0 for no. |
| `generic_cost_per_unit` |  |  | Cost per unit for the generic drug. |
| `generic_cost_at_units` |  |  | Cost for the generic drug at the dispensed units of the brand drug. |
| `tuva_last_run` |  |  | The last time the data was refreshed. Generated by `dbt_utils.pretty_time` as the local time of the `dbt run` environment. Timezone is configurable via the `tuva_last_run` var. |
