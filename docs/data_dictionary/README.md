# Data dictionary

Analyst-facing tables produced by this project (the Tuva Project package, version `0.17.1`). Each mart has its own page listing every table, its grain, and every column.

- Schemas below are the defaults for this project (`tuva_schema_prefix` unset); they are created in your target database.
- Staging (`*__stg_*`) and intermediate (`_int_*`) relations also exist in these schemas but are implementation details and are not documented here.
- See [`../erd.md`](../erd.md) for how the tables join.

_This directory is generated by `docs/tools/generate_data_dictionary.py`; edit that script (or the upstream Tuva YAML), not these files._
